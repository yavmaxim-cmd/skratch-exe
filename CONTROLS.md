# Управление SKRATCH.EXE

## Вертушка и транспорт

Загрузите файл через LOAD AUDIO (допускается несколько) или перетащите аудио в окно. Sample Browser хранит список ссылок на файлы. Синтезированный демо-тон доступен без сторонних записей. Play независим от запуска транспорта DAW; Host Sync использует BPM и, при проигрывании хоста, PPQ для сетки паттернов.

Круговое движение мышью по пластинке задаёт реальную скорость чтения файла, включая отрицательную. При захвате неподвижной пластинки звук останавливается. Отпускание возвращает обычный транспорт. JUCE также получает pointer/touch-события Windows; физическое touch-устройство в этой работе не проверялось.

| Клавиша | Функция |
|---|---|
| A / D удерживать | Назад / вперёд, скорость ×1.7 с чувствительностью |
| J удерживать | Заглушить деку |
| X | Переключить физические края фейдера |
| H | Hamster / реверс фейдера |
| Space | Play / Pause; на сфокусированной кнопке действует стандартная активация кнопки |
| C / V | К CUE / сохранить CUE |
| R | Начать / остановить запись движения |
| Escape | Остановить транспорт, паттерн и playback take |

Щёлкните внутри редактора для фокуса. При перехвате клавиатуры DAW включите передачу клавиш плагину или используйте MIDI. Tab переводит фокус между нативными контролами. На waveform и пластинке стрелки Left/Right изменяют позицию. В редакторе кривых 1/2 выбирают дорожку, Left/Right — узел, Up/Down — значение. В piano roll стрелки выбирают ячейку, Enter добавляет/убирает ноту.

## Mixer

В CUT-режиме входящий бит остаётся слышен, дека открывается возле Cut-In. В Mix-режиме источники смешиваются по equal-power кривой. Hamster меняет стороны фейдера. Reverse рядом с транспортом меняет направление **пластинки** — это отдельная функция.

Curve — степень 0.15–4.0; Cut-In — 0.001–0.4; Response — 0.1–15 ms. На микшере CUT-IN и CURVE находятся в верхнем ряду банка MAIN. BANK переключает верхний ряд на TIME, FEEDBACK, DRIVE и BIT DEPTH. FX включает обработку. Вкладка DJ FX открывает настройки модулей, мотора и восемь Hot Cue. 45 RPM задаёт множитель 1.35 к обычной скорости чтения относительно 33⅓. Индикатор поворота синхронизирован с позицией файла; длина нарисованного оборота соответствует 1.8 s исходного аудио.

## Четыре режима DSP

| Режим | Постоянная сглаживания скорости | Особенность |
|---|---:|---|
| Classic Vinyl | 3 ms | Умеренная инерция |
| Direct Scratch | 0.35 ms | Быстрый отклик |
| Tape Scratch | 25 ms | Медленное ускорение/торможение |
| Digital Scratch | 0.1 ms | Скорость округляется с шагом 1/32× |

Ноль — тишина при неподвижной игле. Высота звука следует скорости. Max scratch speed ограничен ±12×. Это измеримые разные режимы одного настоящего движка чтения аудио, а не проигрывание заготовленных звуков скретча.

## Геймпад

Settings → Input Mapping → RESCAN → выбрать устройство → ENABLE GAMEPAD. При включённом геймпаде центр стика останавливает пластинку даже при Play. Отключение устройства освобождает управление, возвращая транспорт/другой источник.

XInput имеет стандартное назначение осей: LS Y — platter, RS X — fader, LT/RT — замедление/ускорение. Величина скорости пропорциональна отклонению после deadzone и velocity curve. По умолчанию A/Cross — cue+play, B/Circle — stop, X/Square — next cue, Y/Triangle — record, LB/RB — предыдущий/следующий сэмпл, D-pad Left/Right — пресеты. Числа кнопок доступны для изменения.

**Для WinMM/HID, включая режимы PlayStation и Mobapad, назначение не предполагается стандартным.** Смотрите живые A0…A7 и номера нажатых кнопок, выбирайте правильные индексы. Неиспользуемый trigger axis можно поставить в −1. RESCAN показывает только устройства, которые реально выдал backend.

Калибровка: отпустите стики → CAL CENTER; удерживайте оси в минимальных положениях → CAL MIN; в максимальных → CAL MAX. Кнопки снимают значения всех осей одновременно; live bars помогают выставить положения. Калибровка, инверсия, deadzone и ремап сохраняются в mapping preset. При смене USB/Bluetooth/режима устройства повторите выбор и калибровку. Raw HID, не предоставленный Windows как WinMM или XInput, пока не обслуживается; отсутствие отчётов явно видно в диагностике. Это ограничение, а не подтверждённая поддержка всех моделей.

## Паттерны, sequencer и запись

В Scratch Patterns выберите слот, редактируйте обе кривые, задайте длительность в beats, нажмите Preview. TO CUSTOM 1 копирует текущие кривые в первый пользовательский слот. Все 16 слотов сохраняются в project state/preset.

MIDI Sequencer: щелчок в сетке добавляет/удаляет ноту; drag вправо задаёт длину, Shift-drag по вертикали — velocity; щелчок по названию паттерна прослушивает его. Рабочая сетка — один такт, 16 шагов по 1/16. Ноты, добавленные piano roll, имеют приоритет над motion curves во время своей длительности.

Recording: RECORD заменяет текущую take с возможностью Undo. Записываются фактические команды скорости/фейдера, transport, seeks, CUE, tempo и cut. До 120 000 точек на дорожку, примерно 10 минут при 200 Hz. PLAY TAKE / STOP / LOOP TAKE / SNAP 1/16 работают независимо от основного Play. Записанные motion curves имеют приоритет над повторно вычисляемыми паттернами для воспроизводимости жестов. Undo/Redo — один уровень; отдельные изменения узлов считаются отдельными правками. RECORDING — запись управления, не запись итогового WAV.

EXPORT TAKE сохраняет точный JSON, EXPORT MIDI — четыре дорожки SMF, IMPORT принимает оба формата. Save Preset/Load Preset находятся в Presets; mapping-only файлы не заменяют текущую запись.
