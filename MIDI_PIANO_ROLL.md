# MIDI и Piano Roll

Выберите режим в Settings. Ноты применяются на их sample offset в аудиоблоке. Канал MIDI, карта нот и Learn сохраняются. MIDI-выхода нет. Записанное исполнение можно перенести в Piano Roll импортом Standard MIDI File из Recording.

**Scratch Patterns.** MIDI 48–59 запускают встроенные паттерны. MIDI 60–63 назначены Custom 1–4. Последняя нота управляет одной декой. Её удержание повторяет паттерн, Note Off завершает его, повторные Note On перезапускают. При наложении одинаковых нот применяется счётчик удержаний на канал и ноту. Velocity управляет амплитудой и глубиной движения. Траектории скорости и фейдера редактируются отдельно. Длина задаётся в долях, Host Sync использует BPM проекта, Q и Swing меняют сетку начала по выбору. При Q Off старт относится к точному sample offset.

| MIDI | Нота при C4 = 60 | Паттерн |
|---:|---|---|
| 48 | C3 | Baby |
| 49 | C♯3 | Forward |
| 50 | D3 | Backward |
| 51 | D♯3 | Chirp |
| 52 | E3 | Transformer |
| 53 | F3 | Stab |
| 54 | F♯3 | Crab |
| 55 | G3 | Flare |
| 56 | G♯3 | Orbit |
| 57 | A3 | Tape Stop |
| 58 | A♯3 | Reverse |
| 59 | B3 | Scratch Stop |

Если Piano Roll обозначает MIDI 60 как C5, диапазон 48–59 отображается как C4–B4. Ориентируйтесь на номер MIDI. Паттерн можно переназначить в Input Mapping либо кнопкой Learn в Scratch Patterns.

**One Shot.** Нота запускает сэмпл с CUE. Последняя нота занимает одну монофоническую деку. Velocity определяет уровень. Номер ноты не транспонирует файл. Pitch и RPM доступны отдельно. Атака около 1 мс, отпускание около 6 мс. При достижении конца файла голос завершается. Кнопка транспорта Play остаётся независимой.

**Live MIDI.** В Input Mapping доступны Learn скорости, позиции, crossfader, pitch, gain, sensitivity, response, cut-in и curve. CC применяются внутри аудиоблока. Основные CC — 7-битные, позиция и фейдер дополнительно принимают пары MSB/LSB, скорость принимает Pitch Bend. Learn сохраняет назначение, входящие значения влияют на DSP и GUI. Изменение параметра вручную или через автоматизацию хоста снимает соответствующее MIDI-переопределение. В VST3 передача CC зависит от маршрутизации хоста и реализованного JUCE `IMidiMapping`.
