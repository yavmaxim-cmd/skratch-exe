# Installer build

Use Inno Setup 6.4.2 or later. From a source checkout, run these commands with the output and compiler paths adjusted to your environment.

```powershell
python Tools/stage_beta_release.py --build build --output staging --inno-license C:/path/to/InnoSetup/license.txt
$payload = (Resolve-Path staging).Path
& 'C:/path/to/InnoSetup/ISCC.exe' "/DPayload=$payload" '/Orelease' 'Installer/SKRATCH.iss'
Get-FileHash -Algorithm SHA256 release/SKRATCH-EXE-0.9.0-beta-Windows-x64-Setup.exe
```

The staging directory must be new. The staging tool runs the Release audio functional harness to generate the original demo WAV. The installer does not alter DAW settings, install a service or start a program. The wizard refuses to replace an existing unmanaged VST3 of the same name. The uninstaller is generated by Inno Setup and tracks installed files.

On a clean, disposable x64 Windows VM, run `Installer/Test-Installer.ps1 -Installer C:/path/to/Setup.exe -DisposableVm` in elevated PowerShell. Use a VM checkpoint so the entire test environment can be reverted. This is separate from the FL Studio smoke test.
