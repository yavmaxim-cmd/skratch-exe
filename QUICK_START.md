# Quick Start

## FL Studio

1. Close FL Studio and install the required VST3 bundles with the setup EXE. For manual installation, copy the complete bundles to `C:\Program Files\Common Files\VST3`. Reopen FL Studio after changing the files.
2. Open Options → Manage plugins. Select Find installed plugins. If an old copy is cached, enable Verify plugins and Rescan previously verified plugins for the scan.
3. **Instrument.** Add SKRATCH.EXE Instrument to the Channel Rack. It accepts MIDI without audio input. Open the channel's Piano Roll and enter notes. In Scratch Patterns mode use MIDI note numbers 48–63 to trigger the default slots. Octave labels can differ by host. Press Synth Demo in the editor or load a short WAV. Use One Shot mode for normal sample triggers.
4. **FX.** Select a Mixer insert receiving audio and load SKRATCH.EXE FX in an effect slot. In Settings select Live Input to scratch the incoming signal. Play a clip routed to the insert to feed its input history. Select File Deck to scratch a sample loaded into the plug-in. Enable FX and its individual modules when using the DJ FX bank.
5. Save a copy of the FLP under a new name for the first beta session. If the FX file deck uses a local sample, keep that file available.

## Scratch and cut

Drag the vinyl around its centre, or focus the editor and hold A or D. Hold J to cut, press X to switch fader ends, and use C to return to the cue. Use PLAY to run the deck and SET CUE to store a cue. Use the physical crossfader for continuous control. The Scratch Patterns and MIDI Sequencer tabs support drawing and auditioning performance. MIDI Learn is in Input Mapping or beside parameters in DJ FX.

In Standalone, Options → Audio/MIDI Settings selects the device and buffer. Begin with the built-in Synth Demo at low monitoring volume. For live input, use headphones and check the feedback-loop mute.
